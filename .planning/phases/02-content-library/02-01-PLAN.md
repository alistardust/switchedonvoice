Dataclasses (use @dataclass, no __post_init__ needed):
  - Book(id: int, slug: str, title: str, author: str, language: str)
  - Chapter(id: int, book_id: int, number: int, title: str)
  - Passage(id: int, chapter_id: int, position: int, text: str, word_count: int, difficulty: str | None, phonemic_density: float | None, recommended_f0_target: float | None)

BookRepository class (per D-07):
  - __init__(self, db_path: Path) → stores self._db_path: Path
  - list_books(self) → list[Book]: SELECT id, slug, title, author, language FROM books ORDER BY title; return [Book(*r) for r in rows]
  - get_chapters(self, book_id: int) → list[Chapter]: SELECT id, book_id, number, title FROM chapters WHERE book_id=? ORDER BY number
  - get_passages(self, chapter_id: int) → list[Passage]: SELECT id, chapter_id, position, text, word_count, difficulty, phonemic_density, recommended_f0_target FROM passages WHERE chapter_id=? ORDER BY position
  - get_passage(self, passage_id: int) → Passage: same columns FROM passages WHERE id=?; raise ValueError(f"Passage {passage_id} does not exist") if row is None
  - book_exists(self, slug: str) → bool: SELECT 1 FROM books WHERE slug=?; return row is not None
  - ingest(self, data: dict[str, Any]) → None: single transaction inserting book row (with ingested_at = datetime.now(timezone.utc).isoformat()), then chapters, then passages. Use parameterized queries throughout. Passage position: use passage.get("position", idx+1) where idx is enumerate index.
  - update_progress(self, passage_id: int, profile_id: int | None, bookmark_offset: int, completion_count: int, last_attempted_at: str) → None: NULL-safe upsert. When profile_id is None: first try UPDATE WHERE profile_id IS NULL AND passage_id=?; if cur.rowcount==0, INSERT. When profile_id is not None: INSERT OR REPLACE. This pattern is required because SQLite UNIQUE constraints treat NULL≠NULL, so INSERT OR REPLACE would create duplicate rows for NULL profile_id (per research pitfall, D-09).
  - ingest_bundled(self) → None: import importlib.resources; use files("switchedonvoice.content.books") to iterate .sov-book files; call self.ingest(data) for each slug not already in DB. Wrap in try/except ModuleNotFoundError to handle test environments where content package doesn't exist (log with _log.debug and return).

All methods open their own connection and close it before returning (per sessions.py pattern — no shared connections, thread-safe for QThread workers per D-08 research).
  </action>
