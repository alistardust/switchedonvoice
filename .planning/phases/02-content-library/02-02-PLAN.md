<!-- .sov-book JSON structure this tool must produce (per D-01, CONTEXT.md) -->

Required top-level fields: schema_version (int, must be 1), slug, title, author, language, source, licence, version, chapters[]
Required chapter fields: number (int), title (str), passages[]
Required passage fields: slug (str, format: "<book-slug>-ch<NN>-p<NNN>"), position (int, 1-based), text (str), word_count (int), difficulty ("easy"|"medium"|"hard"), phonemic_density (null), recommended_f0_target (null)

PG boilerplate markers (research-verified but verify on actual downloaded files):
  Start: line matching r"^\*{3} START OF THE PROJECT GUTENBERG EBOOK .+\*{3}$"
  End:   line matching r"^\*{3} END OF THE PROJECT GUTENBERG EBOOK .+\*{3}$"

Chapter heading patterns (research Pattern 4 — all 3 PG books):
  Alice (PG #11):  "CHAPTER I." on own line, title on NEXT line
  Oz (PG #55):     "Chapter I" on own line, title on NEXT line
  Anne (PG #45):   "CHAPTER I. Title Here" — title on SAME line as heading

Sentence split pattern (research Pattern 5):
  re.split(r'(?<=[.!?])["\']?\s+(?=[A-Z"])', normalised_text)
  Do NOT use r'[.!?]\s+' — that splits "Mr. Smith" incorrectly.
</interfaces>

Module-level regex constants (named, per no-magic-numbers convention):
  - _PG_START: matches `^\*{3} START OF THE PROJECT GUTENBERG EBOOK .+\*{3}$` with re.MULTILINE. Note: use `.+` (not `\d+`) to match title-based markers used in actual PG UTF-8 files.
  - _PG_END: matches `^\*{3} END OF THE PROJECT GUTENBERG EBOOK .+\*{3}$` with re.MULTILINE.
  - _CHAPTER_HEADING: matches `^(?:CHAPTER|Chapter)\s+([IVXLCDM]+|[0-9]+)\.?\s*(.*)$` with re.MULTILINE. Group 1 = chapter number string, Group 2 = optional inline title.
  - _WHITESPACE: re.compile(r"\s+") for normalisation.
  - _TARGET_PASSAGE_WORDS: int constant = 150
  - _SHORT_CHAPTER_WORDS: int constant = 100

Functions:

def strip_boilerplate(text: str) -> str:
  Use _PG_START.search() and _PG_END.search(). If either is None, raise ValueError("PG boilerplate markers not found"). Return text[start.end():end.start()].strip().

def _normalise(text: str) -> str:
  Return _WHITESPACE.sub(" ", text).strip()

def split_sentences(text: str) -> list[str]:
  Normalise, then re.split(r'(?<=[.!?])["\']?\s+(?=[A-Z"])', normalised). Return non-empty stripped parts.

def split_into_passages(chapter_text: str, target_words: int = _TARGET_PASSAGE_WORDS) -> list[str]:
  Greedy sentence accumulation (research Pattern 5). If the total word count of the chapter is < _SHORT_CHAPTER_WORDS, return the entire chapter as a single passage (without splitting). Otherwise: iterate sentences; when current_words > 0 and current_words + w > target_words, flush current to passages and start new. Flush remaining current at end.

def _assign_difficulty(passage_text: str) -> str:
  Compute avg_words_per_sentence = len(passage_text.split()) / max(len(split_sentences(passage_text)), 1). Return "easy" if avg < 15, "medium" if avg < 20, "hard" otherwise.

def split_chapters(text: str) -> list[tuple[str, str, str]]:
  Use list(_CHAPTER_HEADING.finditer(text)). For each match i: group(1)=roman, group(2).strip()=inline_title. body starts at match.end(), ends at next match start (or end of text). Trim body. If inline_title is empty (Alice/Oz pattern): take the first non-empty line of body as title, remainder as body. Return list of (roman, title, body) tuples.

def build_sov_book(
  slug: str, title: str, author: str, chapter_data: list[tuple[str, str, str]],
  language: str = "en", source: str = "", licence: str = "Public domain", version: str = "1.0"
) -> dict[str, Any]:
  Build the .sov-book JSON structure. First key is `"schema_version": 1`. Convert roman numeral strings to integers using _roman_to_int() helper. For each chapter, call split_into_passages(body). For each passage: generate slug = f"{slug}-ch{chapter_number:02d}-p{position:03d}" (where position is 1-based enumerate index + 1); compute word_count = len(text.split()), difficulty = _assign_difficulty(text), phonemic_density = None, recommended_f0_target = None.

def _roman_to_int(s: str) -> int:
  Simple Roman numeral converter for I–XXXIX (sufficient for all three bundled books). If input is digits, return int(s). Otherwise map standard Roman values. Raise ValueError for unrecognised input.

def main() -> None:

Optional: --slug (required), --title (required), --author (required), --language (default "en"), --source (default ""), --licence (default "Public domain"), --version (default "1.0"). Read input.read_text(encoding="utf-8"). Call strip_boilerplate(), then split_chapters(), then build_sov_book(). Write output.write_text(json.dumps(result, indent=2, ensure_ascii=False), encoding="utf-8"). Print summary: "Written: {output} ({n} chapters, {total_passages} passages)".
